Board Sign Sizes — 24″ wide

A size ladder for printed PVC board signs, capped at 24″ wide. Every height divides evenly into a 4′ × 8′ sheet, so sheets cut with no waste. Name-fit numbers were measured against all 151 names in the trail inventory plus the Green Line sign destinations.

Proposed sizes

4″ header for the brandmark, then 4″ per row. 4-row and 6-row boards use the next size up and the spare height goes to the header.

Sheet yield — 48″ × 96″ PVC

Letter size = type size of the name (current boards use 2.6″). Distances use the common 30–40 ft per inch of letter height for high-contrast signs; riders approach at low speed, so 50–70 ft is enough lead time at most junctions.

Recommendation

  • Width: 24″ for every board.
  • Heights: 8, 12, 16, 24 and 32″ — 1, 2, 3, 4–5 and 6–7 rows.
  • Letter size: 1.75″ names on every board, never shrunk.
  • Numbered symbol: about 2.5″ tall, so 3-digit numbers stay readable.
  • Arrows: 2.5″, at the left or right edge as now. Rows with arrows on both sides lose about 3″ of name space.
  • Green Line badge: under the name at 24″. It only fits beside the name on boards whose arrows are all on one side.
  • Long names: add a short “sign name” column to the trail inventory for the names that don't fit, and print that instead of shrinking the type.
